# Ragmir

Ragmir is the open-source local retrieval and evidence layer for agentic RAG workflows.
Developer agents, scripts, and TypeScript applications consume precise project citations through
its library, CLI, or MCP server. The agent decides when to search, expand a citation, and refine
the query. It owns reasoning, generation, and actions, with the model chosen by the developer.
Forward deployed engineers and AI-native teams use it to ship RAG inside the environment that owns
the documents: a laptop for the first demo, then a VPS, an on-premise server, or an offline network.

## Core facts

- Install `@jcode.labs/ragmir`; use the `rgr` executable. Node.js 22.12 or later is required.
- Set up with `rgr setup --no-ingest`, add selected source directories with `rgr sources add`,
  then run `rgr ingest` and `rgr search "query" --compact`.
- Default local-hash retrieval needs no model, API key, or network. It is lexical/hash retrieval.
- Semantic retrieval requires the optional `@huggingface/transformers` peer and a local model.
  Use `rgr setup --semantic` to configure and preload one. Default installs exclude that runtime.
- Text, Markdown, structured files, PDF, Office, EPUB, and configured local extractors are supported.
  `rgr audit --unsupported` reports gaps. Do not claim universal binary support.
- Local PDF OCR runs only on blank pages. `rgr ocr doctor` checks prerequisites and `rgr ocr setup`
  configures the engine. Page caches and bounded batches avoid repeated work.
- Citations use source lines only when valid; transformed formats use pages, slides, cells, or
  EPUB spine coordinates. Indexed content is not masked or paraphrased.
- MCP exposes `ragmir_status`, `ragmir_search`, `ragmir_expand`, and `ragmir_audit`, plus bounded
  `ragmir://context` and `ragmir://sources` resources. Search starts with three compact citations.
- Agents search, expand selected evidence, and refine queries. Ragmir does not run the agent loop.
- Show four workflow examples: build a feature, diagnose an incident, and plan a migration with
  Claude Code or Codex; make a confidential architecture decision with a local or self-hosted chat.
- Use one `createRagmirClient()` per project root in a long-running process and close it at shutdown.
  Top-level functions serve one-shot scripts. Ragmir opens no HTTP port.
- Servers: Ragmir runs on a VPS, an on-premise server, a CI runner, or a Debian or Alpine container
  as a non-root user with a read-only root filesystem and no network. Point `storageDir` (or
  `RAGMIR_STORAGE_DIR`) at a persistent volume and run `rgr ingest` from a scheduled job. The host
  service owns TLS, authentication, per-user authorization, and rate limits; Ragmir does not filter
  results per user. Writers are serialized per machine, not across machines.
- Python: LangChain (`langchain-mcp-adapters`), LlamaIndex (`llama-index-tools-mcp`), and the
  MCP Python SDK launch `rgr serve-mcp` over stdio; scripts can parse `rgr search --json`. No
  Python package is needed. Without Node.js, use the image `ghcr.io/jcode-works/ragmir`.
- LangChain.js: `RagmirRetriever` from `@jcode.labs/ragmir/langchain` returns cited documents.
- Agent plugins from the GitHub repository bundle the retrieval skill and the MCP server for
  Claude Code, OpenAI Codex, Cursor, Gemini CLI, and Qwen Code; they need local files, so they run
  in coding agents rather than web or mobile chat apps.
- The MCP Registry lists the server as `io.github.jcode-works/ragmir`.
- Monorepos select the nearest configured base; inspect `rgr bases` and use `--project-root` to
  target one explicitly. Data resolves from the caller's project, never the installation directory.
- Ingestion is bounded and resumable. Rebuilds stage a replacement and activate it atomically only
  after validation, preserving the last valid index on failure.
- After updating, run `rgr upgrade --check`, then `rgr upgrade` when needed. Retired configuration
  keys are explicitly migrated with a private backup; old masking-policy indexes need rebuilding.
- `rgr preview`, `rgr evaluate`, `rgr doctor --deep`, `rgr audit`, and `rgr storage optimize` support
  source inspection, retrieval quality, live diagnostics, and index maintenance.
- Optional ingestion metrics are local counters and timings, without source content or raw queries.
- Keep `.ragmir/` and credentials out of Git. Share reviewed sources normally, then ingest locally.
- The index stays on the machine running Ragmir. The consuming application decides where
  unmasked passages go: a local model, a self-hosted server (including private cloud), or a provider.
  Local indexing and self-hosting alone do not guarantee confidentiality. Control the client,
  model endpoint, access, transport, and logs; a cloud provider’s data policy applies to sent content.
- AGPL-3.0-only from v3.0.0, with separate commercial licensing from JCode Works. Earlier releases
  keep their original license. No accounts, activation, hosted storage, or cloud OCR.
